# Player Prop Analysis System (Python, pandas)

## Overview
This repository contains a structured Python-based player prop analysis system built to evaluate sportsbook lines, apply pregame adjustments, and validate results postgame.

The projects progress across multiple iterations, improving decision structure, tracking discipline, and postgame evaluation.

## Core Features
- Baseline vs adjusted projection framework
- Edge calculation logic (projection vs line)
- Structured Over/Under prediction outputs
- Postgame validation using result vs thesis correctness
- Progressive project iterations showing model development

## Tools Used
- Python
- pandas
- Jupyter Notebook

These notebooks use Python and pandas to track market baselines, apply pregame adjustments, and evaluate postgame outcomes through a structured decision-quality framework.

## Projects

### 1. Bears vs Rams Player Prop Analysis
This project tracks baseline sportsbook lines, applies intuition-based adjustments, and evaluates postgame accuracy for the Bears vs Rams divisional playoff game.

**Highlights:**
- Baseline props logged before late-week injuries and market movement
- Adjustments based on matchup, target distribution, and game flow
- Final picks summary included in notebook
- Postgame review explains both hits and misses

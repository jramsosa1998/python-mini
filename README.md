## Player Props Analysis Projects

Small Python scripts and Jupyter notebooks demonstrating Python coding and sports analytics.

## Included Projects

1. **Bears vs Rams Player Props**
   - Tracks baseline player props, adjusts based on trends and injury reports.
   - Calculates pre-game and post-game accuracy.
   - Highlights hits and misses per player and risk tier.

2. **Seahawks vs 49ers Player Props**
   - Same multi-cell workflow: baseline table → adjustments → final summary → post-game accuracy.
   - Handles high-variance props and injury scenarios.
   - Produces CSV snapshots for record-keeping.

## Key Features
- Data analysis with `pandas`
- Table display with `tabulate`
- Accuracy tracking per prop and risk tier
- Multi-cell workflow for structured analysis
- Ready to expand with more games
